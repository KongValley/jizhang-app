# 记账本 · 每天记一笔

一个跑在手机浏览器里的记账 App（PWA）。**所有数据只保存在你自己的设备上**，不需要注册、没有服务端、没有广告，安装到桌面后可以像原生 App 一样离线使用。

## 功能

- **快速记一笔**：支出 / 收入 / 转账三种模式、自定义金额键盘、分类、账户、日期、备注
- **连续记账与成就**：记录连续天数、最长纪录，15 枚成就徽章（笔数、连续天数、预算达成、还清负债、净资产里程碑等），解锁时弹出庆祝动画并轻震动
- **月度小结**：每月生成一份带情绪文案的回顾：结余、钱花在哪、最大一笔、预算是否守住，以及一句属于这个月的总结
- **快捷记账**：常买组合存成模板首页一键记录；备注里直接打「早餐 12」自动识别金额和分类
- **周期账单**：房租、订阅、工资按月/周/年自动记账，也可以到期提醒你确认
- **账单明细**：按天分组、按月切换、账户筛选、全文搜索，点一下即可修改或删除
- **统计图表**：分类占比环形图、近 6 个月趋势、日均 / 单笔平均 / 最大一笔
- **对比与洞察**：今天 vs 昨天、近 7 天 vs 前 7 天、本月 vs 上月同期；分类 6 个月趋势
- **每日热力图**：像日历一样看哪天花得最多，附日均和最忙的一天
- **固定支出**：自动识别房租、话费、订阅这类每月固定开销及其占比
- **年度总结**：全年收支、结余、月均支出、最高支出月份、最常见分类
- **资产负债**：账户可标记为资产或负债，自动计算总资产、总负债、净资产和资产负债率，查看资产/负债构成与 6 个月变化
- **负债还款看板**：为信用卡、房贷、借款设置起始本金、每月还款和年利率，自动算还款进度、预计还清月份和利息；支持目标月份与「月供需要提高到多少」建议，并画出未来欠款走势
- **预算管理**：月度总预算 + 分类预算，进度条、超支提醒、剩余天数与日均可用、复制上月预算
- **日均提醒**：按预算算「今天还能花多少」，连续 3 天超日均会提示
- **多账户**：现金、微信、支付宝、银行卡、信用卡等，支持余额校准（自动补调整记录，不计收支）
- **分类管理**：自定义名称与图标（统一线性 SVG 图标），常用分类可归档隐藏
- **数据安全**：导出 CSV（Excel 可直接打开，转账/调整单独标注）、完整 JSON 备份与恢复
- **外观**：浅色 / 深色 / 跟随系统

> 说明：信用卡、房贷、借款等账户在「账户性质」里选「负债」，欠款会计入总负债并从净资产中扣除；资产账户余额为负（例如微信透支）也会如实反映。

## 为什么这样设计

记账本身是反人性的。除了把数字记准，这一版刻意加了三层情绪反馈：

- **当下有反馈**：记完一笔有轻微震动；连续记账天数常驻首页，今天还没记也不算断签。
- **阶段有里程碑**：15 枚徽章覆盖「第一次」「坚持」「自律」「还清负债」「财富积累」，解锁时给一次庆祝，解锁后永久保留。
- **月末有回望**：月度小结不讲大道理，只讲你自己的生活——钱花在哪、哪笔最贵、预算守住没有，最后用一句话收尾。

所有反馈都可以忽略，不影响记账本身。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
```

手机调试：同一 Wi-Fi 下访问终端里显示的 Network 地址（`http://192.168.x.x:5173`）。

## 构建与部署

```bash
npm run build    # 产出 dist/
npm run preview  # 本地预览生产版本
```

把 `dist/` 部署到任意静态托管（Vercel / Netlify / GitHub Pages / Nginx）即可。PWA 的 Service Worker 需要 HTTPS 或 localhost。

> 注意：应用默认部署在域名根目录。如果要部署在子路径（如 `example.com/app/`），需要给 `vite.config.ts` 增加 `base: '/app/'`。

### 安装到手机桌面

- **Android / Chrome**：打开网页 → 菜单 → 添加到主屏幕 / 安装应用
- **iPhone / Safari**：打开网页 → 分享 → 添加到主屏幕

安装后会全屏运行、支持离线打开。

## 数据说明

- 数据保存在浏览器 `localStorage`（键名 `jizhang.data.v1`），金额以“分”为单位整数存储，避免浮点误差。
- 数据版本升级到 v4：新增转账、余额调整、周期账单、快捷模板、负债还款计划、成就记录，旧数据会在读取时自动补齐字段。
- 转账和余额调整只改变账户余额，不计入收入/支出，也不参与预算和统计。
- 还款进度按「起始本金 − 当前欠款」计算；转入负债账户的转账、收入算还款，消费和转出会增加欠款。
- 提前还清预测按等额月供 + 年利率估算，未计手续费、罚息和利率变动，仅供规划参考。
- 成就解锁后会写入 `settings.seenBadges`，不会重复弹出；断签或余额变化也不会收回已解锁的徽章。
- **清理浏览器数据 / 卸载浏览器 / 换设备会丢失记录**，请定期在「我的 → 备份为 JSON」导出备份。
- CSV 导出带 UTF-8 BOM，中文在 Excel 中不会乱码；转账记录会标注“转出 → 转入”，余额调整单独成行。

## 技术栈

- React 19 + TypeScript + Vite
- 自绘 SVG 线性图标与图表（无图标库、无图表库）
- `vite-plugin-pwa` 生成 Service Worker 与安装清单
- 原生 CSS 设计系统，适配安全区、深色模式、小屏
- 原生 App 壳：Expo + WebView（`mobile-shell/`，独立仓库，EAS 云端构建 APK）

## 图标

界面图标全部是内置的 SVG 线性图标（`src/icons.tsx`），分类图标可在「分类管理」里从 34 个候选中选择。旧版本用 emoji 记录的分类会在加载时自动映射成对应图标，不影响历史数据。

App 桌面图标（`public/icons/*.png`）由脚本生成，改配色后可重新生成：

```bash
node scripts/gen-icons.mjs
```
